# My AI Study Buddy

A Claude Code project designed to help students learn programming through custom AI skills.

## Features

### Study Planner
Creates personalized learning plans.

### Code Explainer
Explains code in simple language.

### Debugging Coach
Helps fix coding errors.

### Quiz Maker
Creates practice quizzes.

### Project Idea Generator
Suggests beginner-friendly projects.
